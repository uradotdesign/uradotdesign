## Directus editing coverage

All 130 non-system collection definitions were reviewed (125 data collections and five navigation folders). Eighteen obsolete interface definitions were replaced; native translations, optional SEO counters, field grouping, human-readable choices, ordering and shared views were standardized. Required hidden legacy titles no longer prevent new translated content from being committed. English fallback backfilling preserves authored translations.

Browser coverage includes the 22 top-level Editor content views, every registered page-builder type, nested pricing tiers, native translation controls, versioned creation/commit, legacy HTML review, media-library/upload controls, editorial dashboards, role switching and the private inquiry workflow. Integration tests separately exercise nested English/German CRUD, saved-version restrictions, trusted-code creation, self-profile access and inquiry field restrictions.

The dashboard walkthrough found relation filters that passed REST but failed Studio's GraphQL requests. Both language and file relation filters now traverse their actual keys. Verification covers 144 REST/GraphQL requests behind the 25 shared views and six repository dashboards. It does not send mail or load private third-party dashboard destinations.

The inquiry list now identifies senders and their preferences. Its status field has New / In progress / Closed / Spam choices and is outside a read-only group so status-only users can operate it. New arrival timestamps are automatic; missing historical dates are recovered only from an existing timestamp or recorded creation activity. Sender details remain read-only, and status changes do not send notifications.

## Verification and limits

- 57 automated tests, ESLint and the production Astro build pass; Astro reports zero errors, warnings or hints across 111 files. Both locked extension builds and their runtime compatibility checks pass.
- The read-only route audit passes all 48 sitemap pages, 14 fallback pages, six representative 1200×630 images, three icon formats and localized 404s. A CMS-unreachable server returns useful localized, private/no-store 500 pages.
- Browser checks cover 375px mobile and desktop, focus wrapping/restoration, theme menus, dialog handoff, multiple contact selections and reduced motion. This is not a screen-reader or full WCAG conformance certification, load test or Core Web Vitals benchmark.
- The root and both extension dependency audits now report zero findings. The previous four shared Unhead development findings were resolved with a verified 2.1.17 peer override; both deployed extension bundles remain byte-for-byte unchanged. CI enforces the audits and compatibility checks.
- The native Directus 12.3.1 Create New loop is corrected in a checksum-guarded local image. Editors see only creatable blocks; Trusted Designers retain code and embed options. Existing blocks and Add Existing retain their behavior; API and saved-version restrictions still enforce permissions. See [the patch and upgrade notes](directus-ui-patch.md).
- Existing unsupported rich HTML remains in Directus's review workflow; it is not bulk-converted. The scheduler releases committed hidden records, not an autosaved future revision of an already public item.
- CMS-only Tailwind additions require a rebuild. Ordinary copy, ordering and visibility changes use normal cache revalidation.
